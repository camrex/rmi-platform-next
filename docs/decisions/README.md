# Architectural Decision Records (ADR)

This directory contains records of the architectural decisions made for the project.

## Format

Each decision is a Markdown file with a front matter block containing:

- `status`: The current status of the decision. Possible values: `ruled`, `tabled`, `open`, `superseded`.
- `kind`: The type of decision (e.g., `architecture`, `technical`, `process`).
- `date`: The date the decision was made (YYYY-MM-DD).
- `refs`: A list of related issues, documents, or other ADRs.

## Workflow

1. Create a new ADR using the template `0000-template.md`.
2. Assign it a unique number (e.g., `0001-my-decision.md`).
3. Discuss the proposal in issues or PRs.
4. Once agreed upon, set the status to `ruled`.
